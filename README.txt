SISTEMA DE GESTÃO DE PATRIMÔNIO - INSTITUTO RECICLAR

Para publicar:
1. Extraia este ZIP.
2. Suba o arquivo index.html para um repositório GitHub.
3. Configure Vercel para deploy do repositório (framework Other; build command vazio; output directory ./).
4. O HTML já contém o logo oficial extraído da primeira página do Guia da Marca.

Observações:
- O sistema usa Firebase Realtime Database/Auth configurado no código e bibliotecas via CDN.
- O deploy em Vercel publica a interface; confirme no Firebase Console as regras de Authentication e Realtime Database para acesso apropriado.
- A senha que já existia no HTML não foi alterada.
